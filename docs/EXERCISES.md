# 演習一覧

[READMEに戻る](../README.md) · [操作ガイド](USER_GUIDE.md)

既存10ケース・104問に、ケース0の導入4問とWeb・DNS/プロキシ/メールの出口演習2本を加えています（通常設問は合計108問）。既存10ケースは正常ログから始まり、「攻撃ログを生成」で調査対象イベントを反映します。ボタンは用意済みのログを切り替えるもので、実際の攻撃を送信しません。

| ケース | 題材・練習すること | 問数 | 目安 |
| --- | --- | ---: | ---: |
| ケース0：検索から根拠保存までの4歩 | 6行から対象選択、可変列抽出、集計、元の根拠保存。省略可能 | 4 | 15分 |
| SSH認証の異常とsudoの追跡 | 認証失敗の分布、成功したログイン、後続の特権操作を時系列で照合する | 10 | 25分 |
| Web探索とデータ出力の照合 | HTTP応答とアプリの業務処理結果を要求IDで結ぶ | 10 | 30分 |
| DNS・プロキシ・メールの横断調査 | 名前解決、HTTP転送、メール配送を送信元・宛先・IDで追う | 12 | 40分 |
| SQLインジェクションと検索結果の異常 | 正当な入力とクエリ構造の変化を区別し、参照・返却行数を確認する | 10 | 40分 |
| コマンドインジェクションと子プロセス | 入力判定、プロセス起動・終了、親子関係、権限を照合する | 12 | 40分 |

目安は画面に表示する学習時間で、制限時間ではありません。SSHケースは初級、ほかは中級です。

## 使うログ

| ケース | 主な仮想ログ |
| --- | --- |
| SSH | `/var/log/auth.log` |
| Web探索 | `/var/log/nginx/access.log`、`/var/log/app/audit.log` |
| DNS・プロキシ・メール | `/var/log/named/query.log`、`/var/log/proxy/access.log`、`/var/log/mail.log` |
| SQLインジェクション | Webアクセス、アプリ監査（テキスト・JSONL）、`/var/log/db/query.log` |
| コマンドインジェクション | Webアクセス、アプリ監査（テキスト・JSONL）、`/var/log/process/exec.log` |
| パストラバーサル | Webアクセス、アプリ監査（テキスト・JSONL）、`/var/log/audit/file.log` |
| Web認証 | Webアクセス、アプリ監査（テキスト・JSONL）、`/var/log/session/events.log` |
| SSRF | Webアクセス、アプリ監査（テキスト・JSONL）、`/var/log/egress/http.log` |
| 不正アップロード | Webアクセス、アプリ監査（テキスト・JSONL）、`/var/log/audit/artifact.log` |
| ログ改変 | Webアクセス、アプリ監査（テキスト・JSONL）、認証・sudo、`/var/log/collector/nginx-access.log` |

アプリ監査の共通パスは `/var/log/app/audit.log` と `/var/log/app/audit.jsonl`、Webアクセスは `/var/log/nginx/access.log` です。同じイベントのテキスト版とJSONL版を合計して数えないようにします。

## ケースの情報を読む

各ケースの **前提・構成** には、次の情報があります。

- 調査を始める状況と目的
- 対象ホストとサービスの役割、通信や処理の流れ
- 正常時に見られる動作
- ログの出所、期間、時刻の扱い
- 演習で与えられる情報の範囲と、確認できない点

全ログは合成データです。WebケースのnginxはJST（+0900）、アプリ監査はUTC（Z）です。他ケースもREADMEの時刻基準を確認し、照合前にそろえます。ホストやサービスの構成は演習の論理的な設定です。記載のない製品バージョン、IPアドレス、実際の権限範囲などを補って結論にしないようにします。

## 学習の支援

各設問には段階的なヒントがあり、解答後には根拠と解説を確認できます。「調査の進め方を見る」には解答につながるコマンド例があります。自力で調査したい場合は、調べたあとに開いて比較してください。

ケースの全問正解後には、攻撃全体の詳しい解説が解放されます。

- 解答に必要な技術知識
- ログから組み立てる攻撃の流れ、原因、影響
- 観測した範囲と、ログだけでは断定できないこと
- 対策と追加調査の視点
- 関連する歴史的な事案・脆弱性と、この演習との共通点や違い
- 外部で読める公式資料・公開ドキュメント

参考リンクは既存10ケースで34件、歴史的な事案は既存各ケースに1件ずつあります。実在の事案をそのまま再現した教材ではありません。関連付けの理由と違いを各解説に記載しています。外部資料の内容や公開先は更新される場合があります。

## 出口演習

| ケース | 構造化して確認するもの | 短い報告 |
| --- | --- | --- |
| Web | 同じ要求のアクセス・監査2行、出力成功の範囲、承認の未確認、追加確認先 | 事実・時刻/IDによる照合・未確認と次の確認を自己比較 |
| DNS・プロキシ・メール | DNS・HTTP送信・メール送信元と配送先受付を支える4行（3種類のログ）、観測事実、内容/承認/侵害の未確認、追加確認先 | 相関と同一内容の断定を分けて自己比較 |

出口の達成は通常104問とは別に保存されます。短文の意味は自動採点しません。既存10ケースと出口2本の完了で、任意の次教材案内を表示します。

基礎欄の任意確認は既存10ケース各1問です。上の108問や卒業条件には算入しません。一般原理を確認するためのもので、当該事案の答えは提示しません。
