LOGROOM v{{APP_VERSION}} · 防御・ログ分析のための演習AIで作成（OpenAI Codex）保存先を確認中

はじめてのLogroom

このアプリとドキュメントは、OpenAI Codex（AI）を使って作成しました。

  1. 正常ログを観察する

    ケースを選び、「前提・構成」で状況とログの範囲を確認します。最初は正常なログだけが入っています。すべて架空のデータです。時刻形式とタイムゾーンはケースのREADMEで確認します。

    cat /home/analyst/README.txt
  2. ボタンで攻撃ログを生成する

    攻撃イベントを演習ファイルに反映します。実際に攻撃を送信したり、SQLやOSコマンドを実行したりすることはありません。入門モードでは正常ログのコピーが /baseline 以下に残ります。実践モードでは過去ログや集計で比較します。

    diff -u /baseline/var/log/auth.log /var/log/auth.log
  3. コマンドで調べて解答する

    検索・集計をパイプで組み合わせ、複数ログの根拠を確認します。「コマンド一覧」、段階的なヒント、解説も使えます。各ケースの全問に正解すると、攻撃全体の詳しい解説が開けます。終了コード1は、grepで一致なし、diffで差分ありの場合も表示されます。

  4. サラの状態からやり直す

    「サラの状態に戻す」で選択中の演習のログ、解答、メモ、履歴、作成ファイルを初期化します。他の演習は保持されます。

再現する範囲

ファイルの移動・表示、検索、集計、差分比較、JSONの抽出、パイプ、仮想ファイルへの出力などを練習します。完全なLinuxシェルではなく、未対応のオプション・構文はエラーになります。サービス起動、パッケージ追加、実ネットワーク通信は行いません。

単独のHTMLファイルで動きます。組織の設定でローカルHTMLの実行が禁止されている場合は、同じファイルを許可された社内Webサイトに配置する必要があります。

less

Space / PageDown でスクロール · / で検索 · n / Shift+N で次 / 前の一致 · q で閉じる

サラの正常状態に戻しますか？

選択中の演習から攻撃ログを取り除き、正常ログだけに戻します。解答、メモ、履歴、仮想ファイルへの変更も消去します。他の演習は保持されます。
